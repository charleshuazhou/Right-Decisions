# 问衡 Wenheng

一个用来把决定摊开的网页。你写下问题、可选项和现实条件，它用生辰八字、姓名和现居所在地，配合易经、紫微斗数、梅花易数或奇门遁甲，整理一则阅读。

档案和历史只存在这台浏览器的 `localStorage` 里。没有配置语言模型密钥时，阅读仍会根据卦辞、星盘和历法生成，并标明这不是模型输出。

这些内容供反省和娱乐，不是财务、医疗或法律建议。

## 本地运行

```bash
npm install
npm test
npm run dev
```

开发服务器在 [http://127.0.0.1:3847](http://127.0.0.1:3847)。

## 环境变量

复制 `.env.example` 为 `.env.local`。三个密钥任选其一；同时存在时优先 `XAI_API_KEY`，其次 `OPENAI_API_KEY`，再次 `AI_API_KEY`。

| 变量 | 作用 |
| --- | --- |
| `XAI_API_KEY` | xAI 密钥。默认请求 `https://api.x.ai/v1` |
| `XAI_BASE_URL` | 可选，覆盖 xAI 的 OpenAI 兼容地址 |
| `XAI_MODEL` | 可选，默认 `grok-3` |
| `OPENAI_API_KEY` | OpenAI 或兼容服务的密钥 |
| `OPENAI_BASE_URL` | 可选，默认 `https://api.openai.com/v1` |
| `OPENAI_MODEL` | 可选，默认 `gpt-4o-mini` |
| `AI_API_KEY` | 没有上面两个密钥时使用的通用密钥 |
| `AI_BASE_URL` / `AI_MODEL` | 通用端点和模型名 |

接口是 `POST /v1/chat/completions`，并要求 JSON 对象。解读语言跟问题本身走：问题以中文为主就用中文，以英文为主就用英文。界面语言是另一只开关。

## 部署到 Vercel

把仓库导入 Vercel，框架选 Next.js。在项目的 Environment Variables 里填上上面的密钥。不填也能上线，只是阅读走离线整理。

`npm run build` 即生产构建。城市列表在 `public/cities.json`，由客户端按需加载。

## 一次问策里有什么

1. **生辰档案**：姓名（中文姓、名，可加英文名）、性别、公历或农历（含闰月）、钟点或时辰、出生地、现居地。出生地用来做真太阳时；现居地用来定问事的当地时辰、流日，以及方位建议。
2. **八字**：年柱以立春为界，月柱以节气为界。23:00 起日柱进一日（晚子时），与紫微的晚子时一致。展示四柱、五行分数、日主强弱、简化的喜用神、调候、大运、流年流月。
3. **姓名**：简体先按 OpenCC 转到繁体，再用康熙笔画算五格（天格、人格、地格、外格、总格）、三才五行，并看人格/总格是否落到八字喜用。笔画可以手改。
4. **易经**：三钱法，可逐次掷，也可一次起完，或填入已经掷出的 6/7/8/9。给出本卦、动爻、之卦，64 卦都有卦名、拼音、英文名、卦辞、爻辞和上下卦。
5. **紫微**：用 [iztro](https://github.com/SylarLong/iztro) 排十二宫、十四主星与辅星、生年四化、当前大限和流年。
6. **梅花易数**：以问事当地时间的农历年月日和时辰起卦，分体用。
7. **奇门遁甲**：用 [qimendunjia-standalone](https://github.com/MrJelly/QiMenDunJia) 的时家拆补盘。问题类型决定看开门、生门、六合、天心、景门或值符。
8. **择日**：往后约 60 天，对照黄历宜忌、与命主年支/日支的冲，以及日干是否为喜用。
9. **方位**：用神、喜神对应的方位、颜色和数字，另附当日喜神、财神、福神。
10. **合盘**：决定若涉及另一个人，可录入对方姓名和生辰，比较日主生克、日支年支的合冲刑害，以及夫妻宫与命宫。
11. **现实条件**：预算、期限、风险承受和直觉，会写进阅读，并在和卦象倾向相反时被点出来。
12. **复盘**：事后记下顺利、含糊或不顺，并可设一个只在本机出现的提醒。复盘页按方法统计说对、没说对和不计入的次数。

问题类型会把紫微的注意力放到对应的宫：事业看官禄，投资看财帛，关系看夫妻，房产看田宅，健康看疾厄，出行看迁移。

## 计算说明

真太阳时 = 当地钟面时间 +（出生地经度 − 该时刻时区中央经线）× 4 分钟 + 均时差。夏令时会改变中央经线。例如 1990 年 6 月中国仍实行夏令时，成都的校正和冬季不同。

喜用神用的是可复核的简化扶抑：月令加权后的五行分数，身强取官杀、食伤、财，身弱取印与比劫。冬月另标火、夏月另标水作调候，不自动并进喜用。这不是一位师傅的完整判断。

五格吉凶用常见的 81 数理表；超过 81 的数按 80 一循环折回。三才看天格对人格、人格对地格是相生、比和还是相克。

## 数据与库

- 卦辞爻辞：[freizl/yijing](https://github.com/freizl/yijing)（MIT），周易原文
- 康熙笔画：[breezyreeds/kangxi-strokecount](https://github.com/breezyreeds/kangxi-strokecount)（MIT）
- 简繁转换字表：OpenCC `STCharacters.txt`（Apache-2.0）
- 城市：GeoNames `cities15000`（CC-BY 4.0），国家名来自 umpirsky/country-list
- 八字、农历与黄历：[lunar-javascript](https://github.com/6tail/lunar-javascript)（MIT）
- 紫微：[iztro](https://github.com/SylarLong/iztro)（MIT）
- 奇门：[qimendunjia-standalone](https://github.com/MrJelly/QiMenDunJia)

重新生成 `data/hexagrams.json`、`data/kangxi.ts`、`data/s2t.ts`、`data/countries.json` 和 `public/cities.json`：

```bash
npm run data
```

脚本读取 `/tmp/wenheng-data` 里预先下载的源文件。日常运行不需要这一步。
